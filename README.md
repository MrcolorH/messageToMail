# 短信转邮件应用 - Android 8.1.0+ 适配版本

## 概述
这是一个Android应用，可以自动将接收到的短信转发到指定的邮箱。应用已经完全适配Android 8.1.0及以上版本的要求。

## Android 8.1.0+ 适配特性

### 1. 后台服务限制适配
- **前台服务**: 使用 `EmailService` 前台服务来处理邮件发送，确保在Android 8.1+上能够正常工作
- **服务类型**: 配置了 `foregroundServiceType="dataSync"` 以符合Android 14+的要求

### 2. 通知系统适配
- **通知渠道**: 实现了Android 8.0+要求的通知渠道 (Notification Channels)
- **通知权限**: 支持Android 13+的运行时通知权限请求
- **前台服务通知**: 前台服务运行时显示持续通知

### 3. 权限管理
应用请求以下权限：
- `READ_SMS` - 读取短信
- `RECEIVE_SMS` - 接收短信
- `RECEIVE_MMS` - 接收彩信
- `RECEIVE_WAP_PUSH` - 接收WAP推送
- `READ_PHONE_STATE` - 读取手机状态（获取设备号码）
- `INTERNET` - 网络访问（发送邮件）
- `POST_NOTIFICATIONS` - 通知权限（Android 13+）
- `FOREGROUND_SERVICE` - 前台服务权限
- `FOREGROUND_SERVICE_DATA_SYNC` - 数据同步前台服务权限（Android 14+）

### 4. API兼容性
- 使用了适当的API版本检查来确保向后兼容
- 修复了已弃用API的使用，如 `SmsMessage.createFromPdu()` 和 `stopForeground()`
- 处理了Android 13+的手机号码获取权限变更

## 技术架构

### 核心组件
1. **SmsReceiver**: 广播接收器，监听短信接收事件
2. **EmailService**: 前台服务，负责邮件发送
3. **NotificationHelper**: 通知管理工具类
4. **MainActivity**: 主界面，处理权限请求和服务控制

### 工作流程
1. 用户启动应用并授予必要权限
2. 应用注册短信广播接收器
3. 收到短信时，SmsReceiver 启动 EmailService 前台服务
4. EmailService 在后台发送邮件并显示通知
5. 发送完成后自动停止前台服务

## 系统要求
- **最低版本**: Android 11 (API 30)
- **目标版本**: Android 14 (API 35)
- **推荐版本**: Android 8.1.0 及以上

## 使用说明
1. 安装应用
2. 首次启动时授予所有请求的权限
3. 点击"开启服务"按钮启动短信监听
4. 配置邮箱设置（在代码中的 SendMail.kt 文件中）
5. 应用将自动转发接收到的短信到指定邮箱

## 注意事项
- 确保设备有网络连接以发送邮件
- 某些设备可能需要在电池优化设置中将应用加入白名单
- 邮箱配置需要使用应用专用密码（如QQ邮箱的授权码）

### vivo手机特殊说明

#### 安装问题解决
如果在vivo手机（FunTouch OS）上遇到"解析包失败"问题：

1. **安装设置**：
   - 进入设置 → 更多设置 → 权限管理 → 安装未知应用
   - 允许从该来源安装应用

2. **系统兼容性**：
   - 应用已降低最低SDK版本至Android 8.1（API 27）
   - 添加了MultiDex支持以提高兼容性
   - 使用调试签名避免签名验证问题

#### 短信接收问题解决
如果应用能正常安装但收到短信不触发邮件发送：

1. **必须设置的权限**：
   - 设置 → 应用管理 → 找到本应用 → 权限管理
   - 开启"短信"、"电话"、"通知"等所有权限

2. **自启动管理**（最重要）：
   - 设置 → 更多设置 → 权限管理 → 自启动管理
   - 找到本应用，开启自启动权限
   - 或者：设置 → 电池 → 后台高耗电 → 允许本应用后台高耗电

3. **后台应用管理**：
   - 设置 → 电池 → 后台应用管理
   - 将本应用设置为"允许后台活动"
   - 关闭"智能省电"对本应用的限制

4. **白名单设置**：
   - 设置 → 电池 → 更多电池设置 → 受保护的后台应用
   - 将本应用加入受保护列表

5. **通知设置**：
   - 设置 → 状态栏与通知 → 应用通知管理
   - 确保本应用的通知权限已开启

6. **调试方法**：
   - 应用会在收到短信时显示"短信接收器触发"通知
   - 如果没有此通知，说明系统阻止了短信广播
   - 请检查上述所有设置项

**重要提示**：vivo系统的省电策略非常严格，必须完成以上所有设置才能确保应用正常工作！
